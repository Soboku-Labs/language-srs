# Flashcard App with Spaced Repetition

A React-based flashcard application that helps you learn effectively using spaced repetition algorithms.

## Features

- Create and manage flashcard decks
- Study cards using a scientifically-proven spaced repetition system (SRS)
- Track your learning progress
- Responsive design that works on desktop and mobile

### Prerequisites

- Node.js 14.0 or later
- npm or yarn package manager
